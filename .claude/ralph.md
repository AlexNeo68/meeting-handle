# Ralph Loop — правила автономной работы

## Общий цикл (управляет `.claude/ralph-start.js`)

`ralph-start.js` — автономный цикл, который сам выполняет все фазы и issues:

1. Для каждой фазы (`config.phases`) пока в milestone есть открытые issues (в порядке возрастания номера — порядок зависимостей):
   - **pre-flight**: если Issue уже упомянута в коммитах ветки (`closes #N` / `#N`) и гейт зелёный — закрывает без сеанса агента;
   - запускает сессию агента на реализацию конкретной Issue;
   - запускает **гейт** (тесты + lint, см. `config.gates`);
   - если гейт красный — запускает сессии починки до зелёного (максимум `maxFixAttempts` попыток);
   - когда гейт зелёный — закрывает Issue;
   - если после всех попыток гейт красный — пишет комментарий в Issue и **переходит к следующей** (фаза не прерывается).
2. Когда issues закончились — создаёт/находит PR и запускает code review.

**Важно:** exit-код агента никогда не прерывает цикл — источник правды это гейт. Один неудачный/зависший сеанс агента не останавливает обработку остальных issues.

## Запуск

```bash
node .claude/ralph-start.js                       # полный прогон
RALPH_DRY_RUN=1 node .claude/ralph-start.js       # без запуска агентов и тестов (гейт считается зелёным)
RALPH_NOOP_GH=1 node .claude/ralph-start.js       # агенты и тесты реальные, gh-действия (close/comment/pr) — noop
```

Переменные окружения:

| Переменная               | Назначение                                                                |
| ------------------------ | ------------------------------------------------------------------------- |
| `RALPH_DRY_RUN=1`        | не запускать агентов и тесты                                              |
| `RALPH_NOOP_GH=1`        | не менять GitHub (close/comment/PR — noop)                                |
| `RALPH_AGENT_BUDGET`     | лимит сеансов агентов (по умолчанию `maxIterations` из конфига)           |
| `RALPH_AGENT_TIMEOUT_MS` | таймаут сеанса агента (по умолчанию 30 мин)                               |
| `RALPH_AGENT_CMD`        | команда запуска агента (по умолчанию `opencode run --auto --agent build`) |
| `RALPH_TESTS`            | переопределить тестовые команды (через запятую)                           |
| `RALPH_GATES`            | дополнительные команды гейта: lint/build (через запятую)                  |
| `RALPH_CONFIG`           | путь к конфигу                                                            |

Лог пишется в `.claude/ralph-loop.log`.

## Как брать Issues

- Читай title, body и критерий готовности: `gh issue view N`
- Если в Issue есть ссылки на PRD (`docs/prd/*.md`) — прочитай их перед реализацией
- Работай только в ветке, указанной в конфиге фазы — не создавай новых веток
- Ветку фазы создаёт сам цикл: фаза 1 — из `main`, следующие фазы — из ветки предыдущей (задачи последующих фаз строятся на коде предыдущих, stacked PRs)
- Если задача **уже реализована** в ветке и работает — проверь это и просто закрой Issue (`gh issue close N`) без лишних изменений

## Именование коммитов

- Conventional commits; в subject **обязательно** указывай номер Issue: `closes #N`

## Правила реализации

- Сначала тесты — потом реализация (TDD)
- После каждого изменения запускай гейт: тесты + lint (команды — в конфиге фазы)
- Не отключай и не удаляй падающие тесты — исправляй причину
- Если менялся UI — прогони UI/UX проверки из `CLAUDE.md`: контраст ≥4.5:1, интерактивные элементы ≥44×44px, alt/aria-label, keyboard nav, без horizontal scroll, анимации 150–300ms и `prefers-reduced-motion`
- Если гейт красный после 5 попыток — остановись, оставь в Issue комментарий с описанием проблемы (это сделает и сам цикл)
- Не создавай PR — это сделает `ralph-start.js` после завершения фазы

## Завершение

- Убедись что гейт зелёный (тесты + lint)
- Убедись что все требования Issue выполнены
- Закрой Issue сам: `gh issue close N`
