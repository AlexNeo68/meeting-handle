# Ralph Loop - правила автономной работы

## Общий цикл (управляет `.claude/ralph-start.js`)

`ralph-start.js` — автономный цикл, который сам выполняет все фазы и issues:

1. Для каждой фазы (`config.phases`) пока в milestone есть открытые issues:
   - запускает сессию агента на реализацию конкретной Issue;
   - запускает тесты фазы (test gate);
   - если тесты красные — запускает сессии починки до зелёных
     (максимум `maxFixAttempts` попыток);
   - когда тесты зелёные — закрывает Issue, если она ещё открыта;
   - если после всех попыток тесты красные — пишет комментарий в Issue и переходит дальше.
2. Когда issues закончились — создаёт PR и запускает code review.

Запуск: `node .claude/ralph-start.js`
Сухой прогон (без запуска агентов и тестов): `RALPH_DRY_RUN=1 node .claude/ralph-start.js`

## Как брать Issues

- Читай title, body и критерий готовности
- Проверяй что указанная ветка уже существует (если нет, создай)
- Работай только в этой ветке - не создавай новых

## Именование коммитов

- По правилам в skill commit

## Правила реализации

- Сначала тесты - потом реализация (TDD)
- После каждого финального изменения запускай тесты
- Не отключай и не удаляй падающие тесты — исправляй причину
- Если тесты красные после 5 попыток - остановись и напиши в Issue комментарий с описание проблемы

## Правила завершения

- Убедись что все тесты зелёные
- Убедись что все требования выполнены
- Запусти skill /review для код ревью
- Закрой Issue
- Не создавай PR — это сделает ralph-start.js после завершения фазы
